# Web 工作台

> 更新日期：2026-10-04

启动服务，浏览会话、文件与执行状态。


## 操作起点

前置：源码构建需要 Rust 与 Node.js/npm，且已配置模型。先运行 `npm ci --prefix crates/mink-server/web`，再构建 server。打开工作台后新建任务，填写服务端机器上的工作目录；看到持久回执才表示输入已接收。

## Web 开发工作台

运行 `mink-server` 后打开 `http://localhost:8765`。桌面左侧按项目列出会话，中间按用户轮次展示对话，右侧按需查看任务、文件、工具输出和诊断。新建任务填写 **server 所在机器的工作目录**；名称可重复，界面生成唯一 alias。切换会话、返回首页或关闭浏览器不会停止任务。

根地址默认进入首页，不自动打开之前选过的会话；导航中的“首页”可随时返回。选中会话后地址包含 `session` / `project`，刷新直接恢复该会话，加载期间不会闪过首页。不存在的会话链接返回首页并说明原因。首页最近会话支持键盘进入。

导航与会话目录只收集用户会话，普通子代理和信号恢复子代理均排除；已有子代理文件保留在磁盘上。

左侧筛选范围可选“全部、项目名称、会话名称、项目路径”。项目名称指工作目录最后一段，会话名称包含标题、别名与 ID；项目路径匹配完整工作目录。切换范围保留关键词，× 清空；只搜索已发现会话，不搜索历史正文。

运行中输入区仍可编辑，发送变为“提交引导”。回执依次显示持久接收与正式上下文交接；当前步骤完成前不会打断工具或模型请求。停止后尚未应用的引导保留，可编辑、移除或点击“用于下一轮”，不会自动启动任务。断线恢复期间保留草稿并禁用提交；⟳ 重新打开和同步会话。停止按钮独立于发送按钮。会话菜单“释放运行时（停止当前任务）”停止并释放执行实例、保留磁盘会话；关闭后点击输入区“重新打开”恢复。

桌面 Enter / Cmd或Ctrl+Enter 提交，Shift+Enter 换行；手机 Enter 换行，通过按钮提交。输入法组合期间不会提交。Ctrl/Cmd+B 切换导航，Esc 先关闭详情或移动导航。顶栏操作菜单 → 设置，可选择浅色/深色、简洁/标准/详细过程，以及导航和详情宽度。思考和工具正文需手动展开。

会话菜单在选择操作、点击外部或按 Esc 后收起。手机导航提供独立关闭按钮，点选当前会话也会返回对话；导航与详情覆盖层约束键盘焦点，关闭后回到入口控件。手机图标按钮保持紧凑（32–36px），会话行 44px；输入、图片和发送/停止合在一个容器内，轮次跳转使用悬浮菜单，快捷键提示收在设置面板中。进入窄屏时自动收起桌面导航，输入区随可视窗口高度调整；草稿恢复后自动重新计算输入框高度。待处理输入单独滚动，停止、编辑、撤回与同步期间显示操作状态并防止重复点击。

文件详情显示当前磁盘内容，可刷新、复制路径、查看行号或 Markdown；目录显示当前位置，文件可返回所在目录，目录可返回上一级，加载与空目录有明确反馈；工具结果与 Artifact 显示当时执行的记录。计划与完整 Todo 只读，调整要求写入输入区交给模型公开工具处理。阅读历史不会被新内容拉回底部；轮次跳转只覆盖已加载内容。每轮“查看过程”展开过程组，“本轮用量”读取权威 outcome；旧记录或供应商未报告时明确显示未知，不补造 Token。

对话复制和文件路径复制支持 Clipboard API 与普通 HTTP 的兼容复制；成功后显示“已复制”或“已复制路径”。浏览器仍拒绝时显示错误，可选择文字手动复制，草稿和光标保留。

展开工具卡片可查看命令/脚本、文件写入内容、子任务和参数字段；“原始参数”手动展开查看完整 JSON。Replace 编辑并列显示旧、新文本，手机纵向排列；Plan/Todo 显示计划正文、任务状态、revision 和变更。调用与执行结果分别保留，子代理与普通工具结果可正常显示 Markdown，Artifact 入口继续保留。

右下角轮次按钮打开纵向列表，最多占 260px 或视口高度的 40%，其余条目在菜单内滚动；支持方向键、Home/End 和点击跳转。

自动换行默认开启：代码、工具输出、文件预览和表格留在当前阅读宽度内。可在轮次菜单的选项框或设置面板开关，刷新后保留；关闭后代码和表格可内部横向滚动，复制和文件正文保持原始内容。

手机阅读时，上滑对话会隐藏顶栏和输入区以增加空间；下滑、轻点正文或按 Esc 恢复。右上小箭头恢复操作栏，左下铅笔恢复输入并聚焦，草稿保留；运行中的停止按钮仍可点击。编辑、附件、待处理引导、失败和恢复提示保持可见，工具卡片内滚动不会触发隐藏。

诊断页与 TUI 状态栏对齐：模型与目录、工作状态/等待时间、轮次/模型请求、输入/输出、缓存命中率及读取/创建/未缓存输入、上下文上限/占比、信念和 Plan/Todo。缓存命中率不包含缓存创建，按完整输入分区计算并取整数；统计缺失显示“—”。运行中切回或刷新恢复当前工作状态。

支持选择、粘贴或拖放 PNG/JPEG/GIF/WebP 图片，实际格式与数量取会话能力交集（最多 8 张，单图/总字节各不超过 core 上限与 16 MiB）。上传中或失败附件阻止提交，移除只解除草稿引用。图片可单独发送；server 生成明确查看路径的请求，只有 `Read` 后进入模型图片上下文。刷新后附件预览与未应用引导可恢复；上传过程被页面刷新打断时需重新选择。

详细 API、快照与生命周期见 [HTTP API](../reference/http-api.md)。

## mink-server：Web 工作区服务器

单二进制 Web 服务（REST + SSE + 嵌入前端），与 TUI/CLI 共享同一 `~/.mink/projects` 会话目录，终端与浏览器可无缝交接。

```bash
cargo build -p mink-server        # build.rs 自动构建并嵌入前端
./target/debug/mink-server        # 默认 8765 端口，读取 ~/.minkrc
MINK_SERVER_PORT=9000 ./target/debug/mink-server
MINK_SERVER_DEV_WEB=1 ./target/debug/mink-server   # 开发模式：服务磁盘 web/dist
```

- 配置优先级：环境变量 > `mink-server.toml` > 项目 `<cwd>/.minkrc` > 用户 `~/.minkrc` > 默认；agent 配置（`[provider]`/`[generation]`/`[context]`/`[tools]`/`[signal]`/`[sandbox]`）与 CLI 同一分组 schema
- 关键环境变量：`MINK_SERVER_HOST/PORT`、`MINK_HOME`、`MODEL`、`MINK_SERVER_MAX_RUNNING`、`MINK_SERVER_TURN_TIMEOUT`、`MINK_SERVER_DEV_WEB`
- REST/SSE API 与事件格式详见 [HTTP API](../reference/http-api.md)

## 启动服务

```bash
# 构建（build.rs 自动执行 npm run build 并嵌入前端）
cargo build -p mink-server

# 运行（默认端口 8765，读取 ~/.minkrc）
./target/debug/mink-server

# 指定端口 / 配置
MINK_SERVER_PORT=9000 ./target/debug/mink-server
./target/debug/mink-server path/to/mink-server.toml
```

打开 `http://localhost:8765` 即可使用 Web 界面。
