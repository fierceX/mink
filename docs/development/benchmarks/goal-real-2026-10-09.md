# Goal 真实模型效果测试：2026-10-09

维护记录；结论只适用于下面的合成小样本。结构化结果见 [JSON](goal-real-2026-10-09.json)，任务正文、初始代码与独立验收源码见 [fixtures](goal-real-2026-10-09-fixtures.json)。

## 结论

两组编码任务在普通模式和 verified Goal 下均通过独立验收，人工续跑均为 0。这个样本没有显示编码成功率提升。Goal 在报告被拒绝后能够自动纠错；明确报告格式的控制组中，独立检查器首次拒绝后自动续跑，第 2 轮验收成功；持续拒绝时在 2 轮预算耗尽后停止，没有提交 completed。

报告协议仍存在模型使用障碍：未提供额外格式提示时，模型会把唯一宿主验收条目拆成多项，把 Read 快照标签、说明文字或不存在的检查器文件当作证据。两组正常 Goal 因此都用了 3 轮；首次拒绝控制组最终耗尽 4 轮预算，虽然代码已通过测试，Goal 仍未完成验收。失败样本没有移除。

## 环境与方法

- 源码 `c5d4d71`，dirty=true，Mink 0.6.7；macOS 15.7.7、Rust 1.99.0。测试二进制 SHA-256 保存在 JSON；这是工作区构建结果，不代表该 commit 的干净发布版本。
- 使用现有 DeepSeek API 凭据，解析后的请求模型为 `deepseek-v4.1-flash-expires-on-0910`（flash 别名）。虽然名称带过期日期，本次 API 仍返回了有效响应和用量；模型名称来自请求及 usage journal，未独立验证服务端权重身份。
- 主样本统一设置 `openai_reasoning_effort=low`、`max_tokens=32768`、每 turn 最多 24 个工具循环；请求期限 180 秒、重试 1 次、工具超时 30 秒、验收超时 60 秒。信号策略沿用默认值。
- 每个样本独立工作目录和 session home，相同初始实现、任务正文及验收脚本。没有加载用户/项目技能；4 个内嵌技能仍可发现。工具为 Read/Write/Edit/Glob/Grep/Bash/GoalReport。
- 普通模式从 CLI 单轮开始，仅当独立检查失败且 turn 未报错时最多人工续跑 3 次。Goal 从 REPL 创建 verified 目标，正常/首次拒绝控制限 4 轮，持续拒绝控制限 2 轮，截止时间 10 分钟、token 软限额 200000。软限额不能中断 turn 内已经开始的工具循环，可能超出。
- 按 JSON 所列顺序串行执行，每种任务/模式仅一个样本；不重置供应商缓存，采样温度沿用供应商默认值。延迟包括 CLI/REPL 启停、模型请求、工具和验收，不能视为纯 Goal 调度性能。
- 检查器位于任务工作目录外，执行后校验 SHA-256 未变。结果以独立检查与 goal.json 终态为准，REPL 进程正常退出本身不表示 Goal 完成。

账本任务有 9 项独立测试，覆盖 CSV 校验、重复 ID、Decimal 汇总、四舍五入、CLI 错误及文档/测试文件。依赖排序任务有 10 项，覆盖稳定拓扑排序、隐式节点、去重、输入不变性、环、错误输入和 CLI。部分测试包含多个子用例。验收源码与 fixtures 均为合成内容。

四个控制组均实际收到独立检查器的拒绝，任务代码最终均通过 10 项测试，人工续跑均为 0。持续拒绝是负控制：代码正确也不满足宿主验收，不得宣告完成。首次拒绝是人为注入的验收基础设施故障，不能当作自然任务成功率样本。

无提示的首次拒绝组在第 3 轮才通过报告结构校验并遇到检查器拒绝；第 4 轮引用了不存在的 `accept.py`，无法完成验收。格式提示组没有观察到 criteria 数量或证据路径拒绝。提示的完整正文保存在 fixtures；它是实验变量，没有修改生产提示或源码。

## 失败与限制

初始连通性尝试受到沙箱 DNS 限制；获得网络执行权限后，真实 API 返回 `pong`。它仅证明连通性，未计入效果对照。最初 DNS 日志被后续 smoke 覆盖，保留此事实，不补造原始文件或哈希。

输出上限 8192、CLI 默认 max 推理强度的普通账本 pilot 因 4 次 length 截断触发 `format_recovery_exhausted`，6 次请求、62483 上报 token、160.11 秒，代码未完成。截断候选未执行。随后启动的同配置 Goal pilot 被实验者主动停止，已上报请求及 token 见 JSON，最后在途用量未知；不计作通过或模型自然失败。之后统一调整两种模式的生成配置，并保留原 pilot。

主测试与控制共 8 个样本、110 次请求、1116361 上报 token，全部有 usage；不包含 smoke、pilot 或未知在途用量。3 个 Goal 终态为 budget_exhausted，没有误报 completed。这里的“误报”仅检查观测终态与独立验收，不表示覆盖所有模型完成声明。

未测长时间真实仓库任务、多模型、多次随机重复、真实远端副作用，也未测试本轮的 Full/Inline TUI。之前的终端模拟测试是独立证据，不混入本次真实模型效果统计。当前证据支持“自动续跑与拒绝完成机制有效”，同时指出报告格式提示不足；不支持整体成功率、成本或性能改善承诺。
