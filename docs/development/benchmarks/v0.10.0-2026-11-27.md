## TUI 渲染结果（`scripts/bench-tui.py`，`release` profile）

| 场景 | 结果 |
|---|---|
| 1 千条消息（40/80/120/200 列 × 12/40 行） | 冷布局 `1.747–4.501ms`；暖输入帧 p95 `0.032–0.131ms`；`history_visits=0, parses=0` |
| 1 万条消息（同宽高矩阵） | 冷布局 `15.662–16.460ms`；暖输入帧 p95 `0.022–0.143ms`；`history_visits=0, parses=0` |
| 约 256 KiB Artifact 详情滚动（4 种宽度） | 平均 `0.040–0.136ms`；`parses=0` |
| 256 KiB 未闭合代码块（256 次增量） | 平均 `0.066–0.249ms`；`line_parses=257` |
| 32 子代理与 32 项待处理输入（4 种宽度） | 绘制 `0.146–0.324ms` |
| 1 万条合成文本事件（`signal_backlog`） | 入队至消费 p95 `1.091ms`，最大 `1.145ms` |
| 可变尾部：约 256 KiB（段落 / 表格） | p95 `4.734ms` / `6.646ms` |
| 可变尾部：约 1 MiB（段落 / 表格） | p95 `19.575ms` / `28.131ms` |
| 测试进程峰值 RSS / peak memory footprint | `138,215,424` 字节（约 `131.8 MiB`） / `26,231,720` 字节（约 `25.0 MiB`） |

相比 [TUI：2026-10-04](tui-2026-10-04.md)：`signal_backlog` p95 从 `1.650ms` 降至 `1.091ms`（-33.9%），32 子代理绘制从 `0.190–0.428ms` 降至 `0.146–0.324ms`，256 KiB 段落可变尾部从 `6.472ms` 降至 `4.734ms`（-26.9%），测试进程峰值 RSS 从 `141.3 MiB` 降至 `131.8 MiB`（-6.7%）。本次未运行真机 PTY / tmux / SSH 交互延迟（`verify-tui-pty.py`）。
