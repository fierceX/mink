# TUI 性能记录：2026-10-04

> 历史维护者测量记录；本次归档未重跑 TUI 矩阵。文中“本次/本轮”指原测量对应的维护工作。

回到[性能与验证](../performance.md)；实现边界见[TUI 实现与维护](../tui.md)。此记录不进入官网产物。

## 测量范围

本机 Apple M4 Pro、Darwin 24.6.0 arm64、rustc 1.98.0。数据来自合成会话、TestBackend 和
本地合成 SSE provider，不含真实模型轨迹、用户会话或网络供应商。另在获准的 SSH 端点
测试 Linux 5.15 x86_64、8 CPU、rustc 1.98.1：同版源码独立构建 debug TUI，使用临时
MINK_HOME，SSH 反向转发连接本地合成 provider，不覆盖远端已安装程序。Full 保持默认模式。

```bash
python3 scripts/bench-tui.py
cargo build -p mink-cli --no-default-features --features tui
python3 scripts/verify-tui-pty.py target/debug/mink
python3 scripts/verify-tui-pty.py target/debug/mink --tmux
# 先在隔离目录构建远端二进制，test-root 必须已存在。
python3 scripts/verify-tui-pty.py /remote/mink --ssh HOST --remote-root /isolated/test-root
python3 scripts/verify-tui-pty.py /remote/mink --ssh HOST --remote-root /isolated/test-root --tmux
```

release 基准通过 Cargo JSON 定位测试可执行文件，随后单独用 `/usr/bin/time` 测量，RSS
不包含 rustc 或链接器。暖缓存每个配置取 100 帧，第 95 个排序样本为 p95；冷布局统计
所有分批布局完成的总耗时，不代表单帧阻塞时间。4ms 处理/布局预算在单个操作之间检查。

## 渲染结果

| 场景 | 结果 |
|---|---|
| 1千条消息，40/80/120/200 列，12/40 行 | 冷布局总计 1.765–2.155ms；暖输入帧 p95 0.017–0.174ms |
| 1万条消息，同宽高矩阵 | 冷布局总计 16.195–17.608ms；暖输入帧 p95 0.014–0.137ms |
| 暖缓存输入帧 | 历史访问增量 0；Markdown/折行增量 0 |
| 约 256 KiB Artifact 详情，四种宽度 | 纯滚动平均 0.039–0.128ms；重新解析 0 次 |
| 256 KiB 未闭合代码块，256 次增量 | 平均更新+绘制 0.066–0.244ms；完整行处理 257 次 |
| 32 子代理与 32 项待处理输入 | 绘制 0.190–0.428ms |
| 1万条合成文本事件，经有界转发桥 | 入队至消费 p95 1.650ms，最大 1.701ms；顺序/数量完整 |
| 整个测试进程最大 RSS（含新增 1 MiB 压力场景） | 148,193,280 字节（约 141.3 MiB） |

基线 warm p95 为 0.033–0.145ms，两次样本均低于 16ms 目标；不能据此宣称所有终端都
有固定倍数提升。本次核心证据是暖输入帧不随历史条数遍历，以及详情滚动不重复解析。
长代码块处理保留前文，不以截掉前 64 KiB 以外内容换取速度。RSS 是测试进程峰值，不能
视为真实会话的稳态内存或 Inline 释放量；后者由提交后正文/缓存为空的回归断言验证。
本轮新增大表格/段落，峰值与上一轮较小套件的 34.9 MiB 不可直接比较，也不能据此断言
内存回归。本组样本没有独立记录复杂结构的临时布局分配及真实会话稳态内存。
事件积压样本测量合成进度流的转发和 reducer，未加入真实模型/磁盘/SSH 网络延迟。

## 剩余可变尾部瓶颈

80×24 release TestBackend，初始化后追加 20 次小片段，取绘制耗时 p95；预先应用片段和
检查稳定前缀不计入以下绘制时间。长连续段落及未结束表格仍整段解析和折行。

| 可变结构 | 约 256 KiB | 约 1 MiB |
|---|---|---|
| 连续段落 | 6.472ms | 21.924ms |
| 增长表格 | 7.226ms | 28.671ms |

普通暖缓存输入帧满足 16ms 目标；不能推广为所有运行态帧都低于 16ms。1 MiB 结构更新
会占用事件循环；本组样本未同时测量重输出期间的输入延迟或单独记录布局分配量。
稳定输出边界仍须完整保留表格与正文，不能用提前提交表格或任意截尾规避成本。

## 终端交互

PTY 和独立 tmux socket 均使用 80×24，另覆盖 40/120/80 列 resize。每个 surface 测量
20 次空闲粘贴、10 次模型等待期间粘贴，检查帮助/统计/输入/详情面板及 Esc 返回、停止、
退出；无 TTY 初始化失败在本地检查。旧探测等满 20ms 读取窗口，约 25ms 的本地结果
包含采样等待；现遇到绘制标记立即返回，计时从写入输入到本地 PTY 首次观察到标记。
SSH 数值包含实际链路往返，不代表 provider 延迟。

| Surface | 模式 | 空闲输入 p95 | 模型等待输入 p95 | 整次输出字节 | 终端恢复 |
|---|---|---|---|---|---|
| pty | full | 1.04ms | 2.65ms | 17,478 | 通过 |
| pty | inline | 2.34ms | 1.57ms | 14,437 | 通过 |
| tmux | full | 1.92ms | 2.64ms | 20,018 | 通过 |
| tmux | inline | 2.06ms | 2.32ms | 20,608 | 通过 |
| ssh+pty | full | 26.84ms | 38.60ms | 19,037 | 通过 |
| ssh+pty | inline | 26.20ms | 42.29ms | 15,608 | 通过 |
| ssh+tmux | full | 29.92ms | 24.75ms | 18,729 | 通过 |
| ssh+tmux | inline | 38.76ms | 35.29ms | 21,684 | 通过 |

本地及 SSH 的 Inline tmux capture-pane 验证稳定标记在 scrollback 仅出现一次。退出后由保持控制终端
的父进程检查 Mink 前后 termios 完全一致；原生 PTY 另检查关闭 bracketed paste 和
Full alternate screen。完全空闲 250ms 的输出为 0 字节。

本地和本次 SSH 样本满足输入到绘制 p95 ≤50ms 的目标。样本为合成模型等待阶段，未覆盖
上述 1 MiB 尾部持续更新叠加输入，也不能保证其他链路、终端模拟器和负载下的延迟。
