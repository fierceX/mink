01 / 轻量与可嵌入

一套 Rust 内核，
接入你的工作方式。

终端里是单二进制的 coding agent。接入应用时，Rust 通过 mink::runtime 在进程内运行；Python SDK 与 Web 服务复用同一内核。

模型后端可替换，工具范围可选择。会话、执行与恢复能力由 runtime 提供。

03 / 可靠编辑与状态

先读，再改。
有歧义，就明确返回。

Hashline 用读取时的快照与锚点定位修改；Replace 用唯一的文本匹配定位。位置不确定时拒绝含糊修改，工具结果进入正式会话。

计划与待办持久保存，待办变更比较 revision；输入有持久回执。执行错误保留真实状态，恢复时有记录可核对。

从 Python 调用运行时。

通过 SDK 管理会话、运行任务和获取结果。Wheel 内置精简核心二进制，复用同一 Rust 内核。

  • pip install mink-agent
  • 显式配置模型与文件访问范围
  • 支持会话生命周期与结构化结果
阅读 SDK 文档 ↗
python / quickstart
# 先运行：pip install mink-agent
import os
from mink_agent import AgentSession, SandboxConfig

session = AgentSession(SandboxConfig(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    read_dirs=["src"],
))
try:
    result = session.run("解释这个项目的结构")
    print(result["text"])
finally:
    session.close()

在 Rust 进程内运行。

通过 mink::runtime 直接在 Rust 进程内运行 agent，管理启动、任务和关闭，无需启动 CLI 子进程。

  • crate：mink-core · library：mink
  • 等待结果，或订阅事件流
  • 可注入自己的 LLM backend
阅读 Rust 嵌入指南 ↗
rust / quickstart
// Cargo.toml：还需添加 tokio 和 anyhow
// mink = { package = "mink-core", version = "0.6.7",
//   default-features = false, features = ["runtime"] }
use mink::prelude::{AgentOptions, AgentRuntime};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let rt = AgentRuntime::start(
        AgentOptions::new("./mink-home", ".")
            .with_api_key(std::env::var("DEEPSEEK_API_KEY")?)
            .with_model("flash"),
    ).await?;
    let result = rt.run_turn("解释这个项目的结构").await?;
    println!("{}", result.text);
    rt.shutdown().await?;
    Ok(())
}
